CentOS 7 无 root 安装 Node.js 22 指南

适用于 glibc 2.17 老系统，解决官方 Node 20 / 22 报 GLIBC_2.27 not found、GLIBC_2.28 not found 的问题。

CentOS 7 glibc 2.17 无 root Node.js 22 linux-x64-glibc-217

核心思路

不使用官方 node-v22.x-linux-x64.tar.xz，而是使用 linux-x64-glibc-217 兼容构建版。

这个版本适合 CentOS 7 / glibc 2.17 这类老系统，可以在无 root 权限下安装到用户目录。

一键安装 检查是否成功 安装 qwen-code 给 Hermes 使用这个 Node 常见问题

一键安装 Node.js 22 glibc 2.17 兼容版

直接复制下面整段执行：

mkdir -p ~/.local
cd ~/.local

rm -rf node22 node-v22.22.3-linux-x64-glibc-217*

curl -LO https://unofficial-builds.nodejs.org/download/release/v22.22.3/node-v22.22.3-linux-x64-glibc-217.tar.xz

tar -xf node-v22.22.3-linux-x64-glibc-217.tar.xz

mv node-v22.22.3-linux-x64-glibc-217 node22

grep -q 'node22/bin' ~/.bashrc || echo 'export PATH="$HOME/.local/node22/bin:$PATH"' >> ~/.bashrc

source ~/.bashrc

which node
which npm
node -v
npm -v

检查是否成功

成功后应该看到类似：

/public/home/freemax/.local/node22/bin/node
/public/home/freemax/.local/node22/bin/npm
v22.22.3
10.9.8

如果 node -v 显示 v22.22.3， npm -v 显示 10.9.8，说明安装成功。

成功标志：

  • node 路径在 ~/.local/node22/bin/node
  • npm 路径在 ~/.local/node22/bin/npm
  • 不再报 GLIBC_2.27 not found
  • 不再报 GLIBC_2.28 not found

安装 qwen-code

Node 成功后，可以安装 qwen-code：

npm install -g @qwen-code/qwen-code

检查安装结果：

npm list -g --depth=0 | grep qwen
which qwen
which qwen-code
qwen --version 2>/dev/null || qwen-code --version 2>/dev/null

启动：

qwen

给 Hermes 使用这个 Node

Hermes 安装器可能会自动下载官方 Node 22，但官方 Node 22 在 CentOS 7 上可能跑不起来。 可以把 Hermes 的 Node 指向刚才安装的兼容版 Node。 

rm -rf ~/.hermes/node

mkdir -p ~/.hermes
ln -sfn "$HOME/.local/node22" "$HOME/.hermes/node"

~/.hermes/node/bin/node -v
~/.hermes/node/bin/npm -v

然后重新安装 Hermes：

export PATH="$HOME/.local/node22/bin:$PATH"
curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash

不建议升级 npm

如果看到：

New major version of npm available!
10.9.8 -> 11.x.x

不建议急着升级 npm。

你的老系统上，当前 Node v22.22.3 + npm 10.9.8 已经可以工作。除非确实遇到 npm bug，否则没必要冒险升级。

常见问题

1. 还是调用到了系统 Node

检查：

which node
which npm

如果不是 ~/.local/node22/bin/node，说明 PATH 顺序不对。

临时修复：

export PATH="$HOME/.local/node22/bin:$PATH"

永久修复：

echo 'export PATH="$HOME/.local/node22/bin:$PATH"' >> ~/.bashrc
source ~/.bashrc

2. 仍然报 GLIBC_2.27 / GLIBC_2.28 not found

说明你可能下载了官方 Node 包，而不是 glibc-217 兼容包。

错误包名通常是：

node-v22.22.3-linux-x64.tar.xz

正确包名应该是：

node-v22.22.3-linux-x64-glibc-217.tar.xz

3. npm 全局命令找不到

检查 npm 全局 bin：

npm bin -g

一般应该是：

~/.local/node22/bin

确保这个目录在 PATH 里：

echo $PATH | tr ':' '\n' | grep node22

总结：在 CentOS 7 / glibc 2.17 / 无 root 环境中，优先使用 linux-x64-glibc-217 兼容版 Node，而不是官方 Node 二进制。

!开始前的安全说明

Cookie 就是登录凭证 获得完整 Cookie 的人，可能在不输入密码的情况下访问你的夸克账号。 不要把 Cookie 发给别人、粘贴到聊天工具、上传网盘或放进截图。
  • Chrome 中已经登录夸克网盘
  • 操作期间不要退出 Chrome 登录
  • 写数据库前先关闭 MoePal
  • 写入前必须备份原数据库

本教程使用 Python 的隐藏输入和 SQLite 参数绑定。粘贴的 Cookie 不会显示在终端，也不会出现在 Shell 命令历史里。

1理解 MoePal 的认证格式

MoePal 没有把夸克登录信息保存在 Wine 注册表、Gecko 或 WebView2 目录中，而是保存在自己的 SQLite 数据库： cloud_storage_auth.db。

数据库字段 夸克所需内容 说明
drive_type quark 必须为小写
auth_data {"cookie":"完整 Cookie"} 必须是合法 JSON，不能直接写原始 Cookie
created_at ISO 8601 时间 首次创建时间
updated_at ISO 8601 时间 最后更新时间

正确的认证对象形式如下：

{
  "cookie": "__pus=……; __puus=……; 其他Cookie=……"
}
不要手工拼接 JSON 字符串 Cookie 中如果出现引号或特殊字符，直接拼接可能破坏 JSON。本教程中的 Python 程序会自动进行 JSON 转义，并使用数据库参数安全写入。

2准备环境并定位数据库

当前电脑上的数据库位置

/home/max/.local/share/deepin-wine-bottles/bottles/Moepal4.2.0.execaa7b95225ec7345b951fe6883435943/drive_c/users/max/AppData/Roaming/com.moecloud.helper/MoePal/MoePal/data/cloud_storage_auth.db

其他电脑如何查找

MoePal 版本或统信 Wine bottle ID 不同时，目录名称可能不同。可以执行： 

find "$HOME/.local/share/deepin-wine-bottles/bottles" \
  -type f \
  -name 'cloud_storage_auth.db' \
  -print 2>/dev/null

为后续命令设置路径变量：

MOEPAL_AUTH_DB='/home/max/.local/share/deepin-wine-bottles/bottles/Moepal4.2.0.execaa7b95225ec7345b951fe6883435943/drive_c/users/max/AppData/Roaming/com.moecloud.helper/MoePal/MoePal/data/cloud_storage_auth.db'

检查文件是否存在：

test -f "$MOEPAL_AUTH_DB" \
  && echo '数据库存在' \
  || echo '数据库不存在，请重新检查路径'

3从 Chrome 获取完整 Cookie

不要使用 document.cookie 浏览器控制台中的 document.cookie 可能读取不到 HttpOnly Cookie。应该从真实网络请求的 Request Headers 中复制。
  1. 用 Google Chrome 打开 https://pan.quark.cn/， 完成登录并确认能够看到自己的文件。
  2. 按 F12 或 Ctrl + Shift + I 打开开发者工具。
  3. 进入“网络”或 Network 选项卡。
  4. 按 Ctrl + R 刷新夸克页面。
  5. 在过滤框搜索 account/info 或 file/sort。
  6. 选择一个发送到 drive-pc.quark.cn 或 pan.quark.cn 的 API 请求。
  7. 打开 Headers → Request Headers → Cookie。
  8. 右键 Cookie 的值并复制。

复制出来的内容通常类似：

__pus=……; __puus=……; tfstk=……; __uid=……; 其他Cookie=……
  • Cookie 是一整行
  • 包含多个“名称=值”
  • 包含 __puus= 或 __pus=
  • 复制的是 Request Cookie

粘贴时可以包含开头的 Cookie:，本教程的写入程序会自动去掉； 但建议只复制字段值。

4完全关闭 MoePal

如果 MoePal 在写入期间仍然运行，可能出现数据库锁定，或者程序退出时用旧数据 覆盖新数据。优先从 MoePal 菜单正常退出。

当前安装也可以使用下面的命令结束 MoePal：

gdbus call --session \
  --dest com.deepin.DeepinWineLauncher \
  --object-path /com/deepin/Manager/Bottles \
  --method com.deepin.Manager.Bottles.killProgram \
  'Moepal4.2.0.execaa7b95225ec7345b951fe6883435943' \
  '75119de5-8897-4dff-ba70-453245c71a88'

检查主程序是否已经结束：

pgrep -af 'C:\\Program Files\\MoePal\\MoePal.exe'
命令没有输出，表示 MoePal 主程序已经退出，可以继续写数据库。

5备份并安全写入 Cookie

下面的程序会完成 Cookie 检查、数据库备份、JSON 转换、参数化写入和权限收紧。 Cookie 在粘贴时不会显示。

粘贴方法 运行后出现 Cookie 提示时，按 Ctrl + Shift + V 粘贴， 然后按回车。屏幕上没有字符回显是正常现象。 
python3 - "$MOEPAL_AUTH_DB" <<'PY'
import datetime
import getpass
import json
import os
import shutil
import sqlite3
import sys
from pathlib import Path

db_path = Path(sys.argv[1])

if not db_path.is_file():
    raise SystemExit(f"找不到 MoePal 数据库：{db_path}")

cookie = getpass.getpass(
    "请粘贴完整的夸克 Cookie，然后按回车（内容不会显示）："
).strip()

if cookie.lower().startswith("cookie:"):
    cookie = cookie.split(":", 1)[1].strip()

if "\n" in cookie or "\r" in cookie:
    raise SystemExit("Cookie 中包含换行，请重新复制为一整行")

if "__puus=" not in cookie and "__pus=" not in cookie:
    raise SystemExit(
        "没有找到 __puus 或 __pus，可能复制的不是完整夸克 Cookie"
    )

if len(cookie) < 120:
    raise SystemExit("Cookie 长度异常，可能没有复制完整")

timestamp = datetime.datetime.now().strftime("%Y%m%d-%H%M%S")
backup_path = db_path.with_name(
    f"{db_path.name}.before-quark-{timestamp}.bak"
)

shutil.copy2(db_path, backup_path)
os.chmod(backup_path, 0o600)

now = (
    datetime.datetime.now(datetime.timezone.utc)
    .isoformat(timespec="microseconds")
    .replace("+00:00", "Z")
)

auth_data = json.dumps(
    {"cookie": cookie},
    ensure_ascii=False,
    separators=(",", ":"),
)

connection = sqlite3.connect(db_path)

try:
    connection.execute("BEGIN IMMEDIATE")
    connection.execute(
        """
        INSERT INTO cloud_auth
            (drive_type, auth_data, created_at, updated_at)
        VALUES
            ('quark', ?, ?, ?)
        ON CONFLICT(drive_type) DO UPDATE SET
            auth_data = excluded.auth_data,
            updated_at = excluded.updated_at
        """,
        (auth_data, now, now),
    )
    connection.commit()

    result = connection.execute(
        """
        SELECT drive_type, json_valid(auth_data), length(auth_data)
          FROM cloud_auth
         WHERE drive_type = 'quark'
        """
    ).fetchone()
finally:
    connection.close()

os.chmod(db_path, 0o600)

if not result or result[1] != 1:
    raise SystemExit("写入后的 JSON 校验失败")

print("写入成功")
print(f"网盘类型：{result[0]}")
print(f"认证 JSON 长度：{result[2]} 字符")
print(f"原数据库备份：{backup_path}")
PY

成功时会看到类似结果：

写入成功
网盘类型：quark
认证 JSON 长度：1262 字符
原数据库备份：……cloud_storage_auth.db.before-quark-时间.bak

6检查写入结果

以下检查只显示结构和长度，不会输出 Cookie：

sqlite3 "$MOEPAL_AUTH_DB" "
SELECT
    drive_type,
    json_valid(auth_data) AS json_valid,
    json_type(auth_data, '\$.cookie') AS cookie_type,
    length(auth_data) AS auth_length
FROM cloud_auth
WHERE drive_type = 'quark';
"

正确结果类似：

quark|1|text|1262
输出 含义
quark网盘类型正确
1auth_data 是合法 JSON
textcookie 字段是字符串
最后的数字认证 JSON 的字符数

检查文件权限：

stat -c '%a %U:%G %n' "$MOEPAL_AUTH_DB"

推荐权限为 600。如有需要可执行：

chmod 600 "$MOEPAL_AUTH_DB"

8常见问题与排查

MoePal 仍然显示“未登录”
  • 确认复制的是 Request Headers 中的 Cookie。
  • 确认 Cookie 包含 __puus= 或 __pus=。
  • 确认没有只复制一个 Cookie，而是复制了完整请求头。
  • 确认写入前 MoePal 已经完全退出。
  • 确认写入的是当前 bottle 使用的数据库。
  • 重新启动 MoePal，不要只返回上一页。
数据库显示写入成功，但文件列表为空

先回到 Chrome 打开 https://pan.quark.cn/。如果 Chrome 也要求重新登录，说明 Cookie 已失效，需要重新登录并再次复制。

提示 database is locked

MoePal 或其 Wine 子进程仍在访问数据库。关闭 MoePal，再使用 pgrep 检查主程序，确认退出后重试。

提示 no such table: cloud_auth

通常是选错数据库，或者 MoePal 尚未初始化“我的网盘”功能。 先启动一次 MoePal、进入“我的网盘”，退出后重新查找数据库。

为什么不能直接执行一条带 Cookie 的 sqlite3 命令？

把 Cookie 直接写在 Shell 命令中会进入终端历史，还可能短暂出现在进程参数里。 此外，Cookie 内的引号和特殊字符可能破坏 SQL。隐藏输入加参数绑定更安全。

9恢复备份与后续更新

恢复修改前的数据库

先关闭 MoePal，再把写入程序生成的 .bak 文件复制回来：

install -m 600 \
  '/完整路径/cloud_storage_auth.db.before-quark-时间.bak' \
  "$MOEPAL_AUTH_DB"

Cookie 到期后更新

  1. 在 Chrome 中重新登录夸克。
  2. 从新的 API 请求复制 Request Cookie。
  3. 关闭 MoePal。
  4. 重新运行“安全写入 Cookie”程序。
  5. 启动 MoePal 并检查文件列表。

当前电脑已有的自动同步工具

如果以后不想手动复制，这台电脑已经有一个本地同步脚本。它会从 Chrome 系统密钥环读取 Cookie，并在写入前验证登录状态。 

/home/max/.local/share/deepin-wine-bottles/tools/sync-moepal-quark-cookie.py --check
/home/max/.local/share/deepin-wine-bottles/tools/sync-moepal-quark-cookie.py
即使使用自动同步脚本，也必须先在 Chrome 中保持夸克已登录。Cookie 失效后无法绕过夸克的正常登录验证。
